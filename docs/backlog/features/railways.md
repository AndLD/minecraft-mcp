# Railways: gaps

**Status:** not planned.

- **Junctions:** joining a new line to an existing one, a branch off a main line, and crossings. Today an existing rail blocks a route (`existing_rail`), so lines never touch. It needs a way to reuse the existing rails as part of the route and to set the switch or junction layout (powered rails and the way a cart is steered).
- **Detector and activator rails:** for stations (a cart stops at a powered rail with no power, and a detector rail can trigger something when a cart arrives). Not part of a plain line; it belongs with stations and junctions.
