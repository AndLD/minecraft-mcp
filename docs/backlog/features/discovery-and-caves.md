# Discovery and caves: gaps

**Status:** not planned.

Left out of the world discovery, biome-guided search, and cave exploration on purpose.

- **Night.** A search or a cave trip does not stop for night or hostile mobs beyond what the survival reflexes do (see [World discovery](../../features/world/world-discovery.md)).
- **A shipwreck signature** (and other structures without one: buried treasure, ocean monuments, trail ruins).
- **Structure signatures read buried blocks** (the scan sees loaded blocks, not only exposed ones), so a temple's TNT chamber is seen from the surface: like an x-ray for those kinds. Only exposed blocks would be more like a regular player.
- **Biome-guided search for mobs** (a mob's biome table is a separate data set) and for the Nether and the End (the search is Overworld only).
- **Boats.** The search is on foot and never crosses water.
- **A table per Minecraft version beyond 1.21.1** ([Biome tables](../../features/world/biome-tables.md)); other versions use the 1.21.1 table.
